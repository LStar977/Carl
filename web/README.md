# Carl — landing page

`index.html` is the marketing/landing page (from the Claude Design handoff).
It's a single self-contained file (inline CSS, no external assets) — host it
anywhere static:

- **Preview locally:** `open web/index.html` (or `python3 -m http.server` from here).
- **Deploy:** drop it on any static host — Netlify, Vercel, Cloudflare Pages,
  GitHub Pages, or an S3 bucket. No build step.

Before launch, fill in:
- the **App Store download link** (currently a placeholder CTA),
- **Privacy Policy / Terms / Support** links in the footer,
- swap the phone-mockup image if you want a real screenshot.
